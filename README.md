# Ultrasonic level gauge — ультразвуковой уровнемер

Электронная шкала уровня жидкости для ёмкости: показывает **высоту столба воды** и **объём** на OLED-дисплее в виде открытого бака со шкалой.

## Для чего

Устройство ставится на **горловину ёмкости** (датчик смотрит вниз на зеркало воды).  
Нужно для наглядного контроля заполнения бака без заглядывания внутрь: оператор видит на экране уровень в сантиметрах, объём в кубометрах и «живую» картинку заполнения.

Типичный сценарий: стационарная ёмкость с известным полным объёмом и высотой дно→горло; прибор монтируется в корпус указателя рядом с баком.

## Что делает

1. Ультразвуковой датчик измеряет расстояние до поверхности воды (или до дна, если пусто).
2. Прошивка переводит дистанцию в **высоту воды** и **объём** по двухточечной калибровке (пусто / полно), с учётом мёртвой зоны датчика (~20 см).
3. На OLED рисуется:
   - открытая ёмкость со шкалой объёма (0 / 4 / 8 / 12 м³);
   - заливка «воды» с волной по зеркалу;
   - по центру объём `XX.YY` м³;
   - сверху высота воды `0…165 cm` (не сырая дистанция датчика).

Сейчас на стенде откалибровано под ёмкость **~12 м³**, высота дно→горло **1.65 м**.

| Состояние | Датчик (примерно) | На экране |
|-----------|-------------------|-----------|
| Пусто | ~185 см до дна | `0 cm`, объём `0.00` |
| Полно | ~20 см (мёртвая зона) | `165 cm`, объём `12.00` |
| Ближе 20 см | эхо может пропасть / зажим | остаётся полно |

## Железо

| Узел | Сейчас |
|------|--------|
| Контроллер | Arduino Nano 3 (ATmega328) |
| Дисплей | OLED 0.96" 128×64 I2C (SSD1306), 4 пина; в корпусе планируется **2.4" SSD1309** (то же разрешение 128×64) |
| Датчик | Ультразвук в режиме **TRIG/ECHO** (рабочий на реальном железе) |
| Питание | 5 V, общий GND |

### Распиновка (Nano)

| Сигнал | Пин |
|--------|-----|
| OLED SDA | A4 |
| OLED SCL | A5 |
| OLED (4-пин, без RES) | `OLED_RESET = -1` |
| Датчик TRIG | D9 |
| Датчик ECHO | D10 |
| LED «датчик OK» | D8 → 220…470 Ω → LED → GND (не вешать на Echo!) |

Адрес OLED обычно `0x3C`.

## Калибровка

Все константы с меткой `<<<` в блоке калибровки в `src/main.cpp` (и зеркально в `sketch_jul17a/sketch_jul17a.ino`):

| Константа | Смысл |
|-----------|--------|
| `TANK_CAPACITY_M3` | полный объём, м³ |
| `TANK_HEIGHT_M` | высота столба воды дно→горло, м |
| `DIST_FULL_CM` | рулетка: датчик → зеркало при полной (~20) |
| `DIST_EMPTY_CM` | рулетка: датчик → дно при пустой (≈ высота_см + DIST_FULL) |
| `DIST_OFFSET_CM` | мелкий сдвиг, см |
| `CALIB_TOL_CM` | допуск «уже полно/пусто» |

## Сборка и прошивка

1. В VS Code / Cursor: **File → Open Folder** → корень репозитория (здесь лежит `platformio.ini`).
2. Не создавай PlatformIO-проект *внутри* уже открытой папки с тем же именем — появятся вложенные дубли.
3. PlatformIO: Build / Upload.
4. Исходник для PlatformIO: `src/main.cpp`.  
   Копия для Arduino IDE: `sketch_jul17a/sketch_jul17a.ino` (держи их одинаковыми).

Зависимости заданы в `platformio.ini` (Adafruit SSD1306 + GFX).
